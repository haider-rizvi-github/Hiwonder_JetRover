# Hiwonder JetRover ROS 2 Workspace

This workspace contains ROS 2 packages for visualizing, simulating, and controlling a Hiwonder JetRover robot model. It includes Xacro/URDF descriptions, STL meshes, RViz and Gazebo launch files, ros2_control controller configuration, and joystick teleoperation support.

## Repository Layout

```text
.
├── src/
│   ├── jetrover_description/
│   │   ├── launch/      # RViz and Gazebo launch files
│   │   ├── meshes/      # Chassis, wheel, arm, gripper, LiDAR, and sensor meshes
│   │   ├── urdf/        # Xacro robot description files
│   │   ├── CMakeLists.txt
│   │   └── package.xml
│   ├── jetrover_controller/
│   │   ├── config/      # ros2_control and joystick teleop parameters
│   │   ├── launch/      # Controller and joystick launch files
│   │   ├── CMakeLists.txt
│   │   └── package.xml
│   └── README.md
├── build/               # Generated by colcon
├── install/             # Generated by colcon
└── log/                 # Generated by colcon
```

## Packages

- `jetrover_description`: robot model package for the JetRover chassis, arm, gripper, LiDAR, IMU, and depth camera.
- `jetrover_controller`: controller configuration and launch support for `joint_state_broadcaster`, `mecanum_drive_controller`, arm trajectory control, gripper position control, and joystick teleoperation.

## Model Options

Supported chassis values:

- `JetRover_Mecanum`
- `JetRover_Tank`
- `JetRover_Acker`

Supported LiDAR values:

- `A1`
- `A2`
- `C1`
- `S2L`
- `LD14P`
- `G4`

The launch files default to `machine_type:=JetRover_Mecanum` and `lidar_type:=A1`.

## Prerequisites

Install ROS 2, Gazebo, and the ROS packages used by the launch files. Package dependencies include:

- `ament_cmake`
- `controller_manager`
- `ros2_control`
- `ros2_controllers`
- `hardware_interface`
- `joint_state_broadcaster`
- `joint_trajectory_controller`
- `mecanum_drive_controller`
- `position_controllers`
- `joy`
- `joy_teleop`
- `gz_ros2_control` or `ign_ros2_control`, depending on ROS 2 distribution
- `ros_gz_sim`
- `ros_gz_bridge`

The launch files also use common ROS 2 tools such as `xacro`, `robot_state_publisher`, `joint_state_publisher_gui`, and `rviz2`.

## Build

From the workspace root:

```bash
colcon build --symlink-install
source install/setup.bash
```

To rebuild only these packages:

```bash
colcon build --symlink-install --packages-select jetrover_description jetrover_controller
source install/setup.bash
```

## View in RViz

Launch the robot description in RViz:

```bash
ros2 launch jetrover_description display.launch.py
```

Select a chassis or LiDAR model:

```bash
ros2 launch jetrover_description display.launch.py machine_type:=JetRover_Mecanum lidar_type:=A1
ros2 launch jetrover_description display.launch.py machine_type:=JetRover_Tank lidar_type:=G4
ros2 launch jetrover_description display.launch.py machine_type:=JetRover_Acker lidar_type:=A1
```

## Run in Gazebo

Spawn the JetRover model in an empty Gazebo world:

```bash
ros2 launch jetrover_description gazebo.launch.py
```

With explicit model options:

```bash
ros2 launch jetrover_description gazebo.launch.py machine_type:=JetRover_Mecanum lidar_type:=A1
```

Gazebo-specific options:

```bash
ros2 launch jetrover_description gazebo.launch.py enable_ros2_control:=true enable_gazebo:=true
```

## Launch Sequence

For a full Gazebo simulation with controllers and joystick teleoperation, use three sourced terminals.

Terminal 1: start Gazebo and spawn the robot.

```bash
source install/setup.bash
ros2 launch jetrover_description gazebo.launch.py
```

Terminal 2: start the ros2_control controllers.

```bash
source install/setup.bash
ros2 launch jetrover_controller controller.py
```

Terminal 3: start joystick teleoperation.

```bash
source install/setup.bash
ros2 launch jetrover_controller joystick_teleop.launch.py
```

The joystick launch starts:

- `joy_node` from the `joy` package
- `joy_teleop` from the `joy_teleop` package
- `arm_gripper_teleop.py` from `jetrover_controller`

## Start Controllers

After launching the Gazebo simulation with ros2_control enabled, start the controller spawners in another sourced terminal:

```bash
source install/setup.bash
ros2 launch jetrover_controller controller.py
```

This launch file starts the controllers in order:

1. `joint_state_broadcaster`
2. `mecanum_drive_controller`
3. `arm_controller`
4. `gripper_controller`

## Generate the URDF Manually

The launch files generate the robot model from:

```text
src/jetrover_description/urdf/hiwonder_jetrover.xacro
```

You can generate a URDF directly with:

```bash
MACHINE_TYPE=JetRover_Mecanum LIDAR_TYPE=A1 \
  xacro src/jetrover_description/urdf/hiwonder_jetrover.xacro > jetrover.urdf
```

For a simulation-ready URDF:

```bash
MACHINE_TYPE=JetRover_Mecanum LIDAR_TYPE=A1 \
  xacro src/jetrover_description/urdf/hiwonder_jetrover.xacro \
  enable_ros2_control:=true enable_gazebo:=true > jetrover_sim.urdf
```

## Troubleshooting

- If ROS cannot find a package, rebuild the workspace and run `source install/setup.bash` in the current terminal.
- If Gazebo cannot find meshes, launch through `gazebo.launch.py`; it sets `GZ_SIM_RESOURCE_PATH` for the installed package location.
- If controllers fail to spawn, make sure Gazebo is already running and the robot was launched with `enable_ros2_control:=true`.
- If RViz opens without the expected model, check that the selected `machine_type` and `lidar_type` values match the supported options above.

## Notes

- `build/`, `install/`, and `log/` are generated workspace folders and can be recreated with `colcon build`.
- `display.launch.py` publishes the robot description and starts RViz with a joint state publisher GUI.
- `gazebo.launch.py` starts Gazebo, publishes the robot description with simulation time enabled, and spawns the robot from the `robot_description` topic.
- `jetrover_controller/config/controller.yaml` contains the controller names and parameters used by the controller spawner launch file.
- `joystick_teleop.launch.py` loads `joy_config.yaml`, `joy_teleop.yaml`, and `arm_gripper_teleop.yaml` for joystick input, base motion, and arm/gripper control.
