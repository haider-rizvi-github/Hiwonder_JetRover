# Hiwonder JetRover ROS 2 Description

This repository contains a ROS 2 description package for the Hiwonder JetRover robot. It includes Xacro/URDF robot models, STL meshes, and launch files for viewing the robot in RViz or spawning it in Gazebo.

## Repository Layout

```text
.
├── jetrover_description/
│   ├── launch/      # RViz and Gazebo launch files
│   ├── meshes/      # Robot, wheel, arm, gripper, LiDAR, and sensor meshes
│   ├── urdf/        # Xacro robot description files
│   ├── CMakeLists.txt
│   └── package.xml
├── build/           # Generated by colcon
├── install/         # Generated by colcon
└── log/             # Generated by colcon
```

## Package

- `jetrover_description`: robot description package for JetRover chassis, arm, gripper, LiDAR, IMU, and depth camera components.

Supported chassis options:

- `JetRover_Mecanum`
- `JetRover_Tank`
- `JetRover_Acker`

Supported LiDAR options used by the launch files:

- `A1`
- `A2`
- `C1`
- `S2L`
- `LD14P`
- `G4`

## Prerequisites

Install ROS 2 and the description/simulation dependencies used by the launch files. The package declares dependencies on:

- `ament_cmake`
- `controller_manager`
- `ros2_control`
- `hardware_interface`
- `joint_state_broadcaster`
- `joint_trajectory_controller`
- `mecanum_drive_controller`
- `gz_ros2_control` or `ign_ros2_control`, depending on ROS 2 distribution

The launch files also use common ROS 2 tools such as `xacro`, `robot_state_publisher`, `joint_state_publisher_gui`, `rviz2`, and `ros_gz_sim`.

## Build

From the workspace root:

```bash
colcon build --packages-select jetrover_description
source install/setup.bash
```

If this `src` directory is inside a larger ROS 2 workspace, run the build from that workspace root instead:

```bash
cd ..
colcon build --packages-select jetrover_description
source install/setup.bash
```

## View in RViz

Launch the robot description in RViz:

```bash
ros2 launch jetrover_description display.launch.py
```

Select a chassis or LiDAR model:

```bash
ros2 launch jetrover_description display.launch.py machine_type:=JetRover_Mecanum lidar_type:=A1
ros2 launch jetrover_description display.launch.py machine_type:=JetRover_Tank lidar_type:=G4
ros2 launch jetrover_description display.launch.py machine_type:=JetRover_Acker lidar_type:=A1
```

## Run in Gazebo

Spawn the JetRover model in an empty Gazebo world:

```bash
ros2 launch jetrover_description gazebo.launch.py
```

With explicit model options:

```bash
ros2 launch jetrover_description gazebo.launch.py machine_type:=JetRover_Mecanum lidar_type:=A1
```

## Generate the URDF Manually

The launch files generate the robot model from:

```text
jetrover_description/urdf/hiwonder_jetrover.xacro
```

You can generate a URDF directly with:

```bash
MACHINE_TYPE=JetRover_Mecanum LIDAR_TYPE=A1 \
  xacro jetrover_description/urdf/hiwonder_jetrover.xacro > jetrover.urdf
```

## Notes

- `build/`, `install/`, and `log/` are generated workspace folders and can be recreated with `colcon build`.
- `display.launch.py` publishes the robot description and starts RViz with a joint state publisher GUI.
- `gazebo.launch.py` starts Gazebo, publishes the robot description with simulation time enabled, and spawns the robot from the `robot_description` topic.
- Gazebo mesh lookup is configured through `GZ_SIM_RESOURCE_PATH` in the Gazebo launch file.
